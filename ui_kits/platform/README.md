# Filocalia web platform (UI kit)

Interactive prototype built from the design-system foundations — **not** a recreation of an existing product (none was provided).

Flow: Catalogue (filter by discipline) → Course detail (pick a date) → Booking (details + optional coaching) → Confirmation → Learning-tour calendar (filter by country, save a spot). Services/Coaching nav items show a "coming soon" toast.

Open `Filocalia Platform.dc.html`. Styling uses tokens from `../../styles.css`; patterns mirror the components in `components/` (pill buttons, arch cards, keystone tabs, plum toast).
